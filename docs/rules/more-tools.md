# 新增五项迁移说明

本批为 Mac 开发验证版，源自原部署包的反编译逻辑。输入文件不改写，输出存在时需确认覆盖；处理在本机完成。测试使用虚构样例，尚未完成实际项目数据与原系统的逐份对照及 Windows 验证。

## 4 超限价及税率核验

输入行报价工作簿和限价清单；可从界面导出空白模板。报价工作簿每个工作表名称作为分标，采购申请号匹配限价。报价单位万元、限价单位元，自动换算。检查超过限价、等于限价、非13%税率、同包同轮同物料的相同报价、同供应商第二轮报价上涨。税率口径沿用旧版，须结合项目规则复核。

输出统一为报价核验.xlsx。与旧版区别：逐项列出全部问题，不只保留供应商的首个问题；相同报价逐物料列出，不合并多个物料的供应商组合。缺少限价明确提示，不能作为通过；重复同供应商同物料同轮报价拒绝处理。界面默认服务模式：不读取单价；总价或折扣率有值时确定报价方式，两者同时有值拒绝处理以免误判。总价万元与限价元换算；折扣率按百分数比较，支持88、88%及Excel百分比格式。服务类限价表必需“报价方式”列，填总价或折扣率（兼容总价报价/折扣率报价）。总价限值单位元；折扣限值是比例，1=100%。绝不根据限值大小推断报价方式；相同数值1在总价行仍按1元处理。报价表识别方式须与限价表一致，否则提示口径不一致。只对当前报价涉及的限价记录检查方式，缺失/待确认明确列为未核验，不影响无对应报价的限价行。单价、总价、折扣率及折扣上限分别输出，二轮上涨说明使用对应单位。

物资模式保留单价优先、缺失时总价的行为，限价口径为单价或总价。两种模式都不把缺值当0，不混比不同报价口径。税率允许清单可由用户指定（逗号分隔，支持小数及%）；输入框留空或填写自动时使用默认：服务0、1、3、5、6、9、13，物资13。清单外输出“税率异常”。证明核查清单默认0、1，命中输出“税率证明待核实”，可填无关闭；不直接认定小规模纳税人身份或证明缺失。这些是用户配置的复核规则，不是自动税务合规结论。

限价表使用分标名称，与报价工作表名称共同限定采购申请标识的匹配范围。仅在同分标内，采购申请号完整匹配优先，否则截去末5位匹配；输出保留原值与匹配值，不合并报价行。不同分标可重复标识，同分标重复仍拒绝处理。旧分标编号模板须先转换为名称，不自动忽略分标关联。

## 6 初评汇报

输入工作簿至少3个工作表，顺序为否决明细、基本情况、组长信息，布局沿用原系统。第一张表第3行起B—E列依次为分标、原因、供应商、包；第二张表A列使用“一、基本情况”“二、澄清事项”定位，汇总C—E列；第三张表A2提取组别、A11读取“组长：姓名”。组别可在界面覆盖。

生成初评汇报单.docx，包含标段数、包数、投标人数、文件份数和否决明细。保留完整供应商名称；澄清事项由用户填写，空白标注待核实，不沿用旧模板自动填“无”。输出为待人工复核的汇报稿。

## 7 履约分生成

输入开标及部门信息、履约评价表，可导出模板。以单位及供应商关联，按关联类型追加分标或所属部门。A/优秀=5、B/良好=4、C/一般=3、D/及格=2、E/不及格=1；数值≥90=5、>80=4、>60=3、>30=2、<30=1。

保留旧版特殊语义：空白、/、文字“0”为默认4；“0.0”按数值为1。恰好30和无法识别的非空评价不覆盖已有有效评价，没有有效匹配时默认4；这些情形在输出中提示。多条关联取末条有效评价并提示。未知关联类型及缺失关联键拒绝处理。

## 8 专家总分校验

输入一个或多个原格式专家总分工作簿。每页高度为专家人数+7，第四行起为供应商名称，第五行起为专家评分，后接平均分行。检查任意两名专家分差严格大于阈值（默认7）和超过半数专家同分。恰好半数、恰好等于阈值不预警。支持加密工作簿，口令仅本次使用。

输出专家总分核验.xlsx，仅列问题并给出来源位置。分差预警列出实际分差、高分、低分及双方专家姓名（从A列“编号_姓名”提取下划线后的部分）；同分预警列出对应专家。姓名空白时明确标注未填写；G列保留投标人位置。不同专家的同一高低分组合分别保留。缺失供应商名称却有分数、专家人数不一致、错误单元格均拒绝处理。修正旧版零分同分遗漏；使用底层数值而非显示四舍五入值。

## 12 否决原因公示

输入否决明细和分标顺序，可导出模板。按分标、否决原因归并；投标人数按供应商去重，文件份数按记录行数。未知分标置末尾并提示；缺少原因、相冲突的分标顺序拒绝处理。

输出否决事项公示.docx，A4表格。不使用旧版“中标候选人公示”标题，因为本工具没有中标候选人数据。请先排除重复导入的明细行，以免文件份数重复计数。

## 工具6：名称配置与包号归并（2026-10-26）

面板提供简化公司名称开关、逗号分隔后缀列表和保存名称配置按钮。默认使用已分析Windows进阶版的七项后缀，最长优先，仅从末尾重复删除。可直接编辑列表添加或删除，留空或取消勾选保留全称；编辑对当次执行生效，保存后重启保留。配置保存在~/.tender-toolbox/initial-report-names.properties，更新时备份.bak并原子替换。归并仍使用完整公司名称；不同企业简称冲突时保留全称，防止误合并。

否决明细按分标、原因、企业归并；包号支持包1、包1至包3以及逗号/顿号分隔，按数字排序去重并合并连续区间，区间不展开成逐包列表。无法解析的包号明确报错，不静默忽略。分标、原因、企业保持首次出现顺序。当前Word版式和澄清事项填写逻辑保留。
