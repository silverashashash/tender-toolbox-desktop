# 工具5 价格分自动计算

## 输入与边界

选择已确认有效、进入详评的报价文件（可多选）及一份公式参数表。程序不自动判断供应商是否应否决；在可选列“是否参与计算”填“否”可排除，填“是”或空白按参与计算处理；不得把已否决报价放入均值计算。
报价表识别表头，可直接读取包含下列列的开标一览表或填写模板：分标名称、分包名称、轮次、投标人名称、投标价格（万元）、折扣率。报价两列必须恰好填写一项；缺少的一列可以不提供。总价以万元输入，折扣率写90%或0.9，勿以无百分号的90表示90%。支持Excel百分比数值格式。零/负报价不计算。

按分标名称＋分包名称计算，各包只允许一个轮次；“计算轮次”留空时自动检查，填写时仅选择完全匹配的轮次。重复供应商、混合总价/折扣率均拒绝。不同批次同名分标、包不可混选。

参数表每分标一条：分标名称、价格公式、qz及相关参数。价格公式支持以下中文名或编码。qz是价格权重0到100（如60），c等系数按小数填写。各参数必须依照本批采购文件，程序不填业务默认值。

## 六种公式

A是包内有效报价均值，B是基准值，P是某投标人报价。除公式3外，价格分=max(0,100−100×n×|P−B|÷B)，P≥B时n取n1，否则n2；公式5改用F1、F2。

1. 10013001 区间平均价浮动法：≤5家不去极值；6–10家去1高1低；11–20家去2高1低；21–30家去3高2低；>30家去4高3低。剩余均值T，在剩余报价中按闭区间[(1+w1)T,(1+w2)T]筛选，B=筛后均值×(1−c)，无报价落入则用T。
2. 10013002 算术平均值下浮法：B=A×(1−c)。
3. 10013003 区间平均下浮双边曲线算法：闭区间[F1×A,F2×A]筛选，B=(筛后均值或无报价落入时A)×(1+c)。P≥B时分数=100×(B/P)^n1，否则100×(P/B)^n2。
4. 10013004 区间复合平均价法：闭区间[(1+b)A,(1+c)A]筛选，B=筛后均值；筛选为空时，最低价唯一则B=(A+最低价)/2。最低价并列时拒绝，因原版求所有并列最低价之和，需确认采购文件口径。
5. 10013005 算数平均值浮动法：剔除P<A×(1−m)，B=保留报价均值×(1+c)，高低系数分别F1/F2。
6. 10013006 区间复合平均价浮动法：≤5家B=A×(1+c)；>5家以开区间((1+a)A,(1+b)A)筛选，B=(筛后均值或无报价落入时A)×(1+c)。

参数范围沿原版：n1/n2>0；1的w1∈(-1,0)、w2∈(0,1)；3的F1∈(0,1)、F2∈(1,2)；4的b∈(-1,0)、c∈(0,1)；5的F1/F2>0、m∈[0,1)；6的a∈(-1,0)、b∈(0,1)。除4外c∈(-0.1,0.1)。

中间均值使用十进制18位，扣分或曲线比值除法四舍五入6位，价格分2位，加权价格分=价格分/100×qz再四舍五入2位。基准值展示6位，计算使用未作展示舍入的值；总价按万元、折扣率按百分数展示。结果含来源文件、工作表、行号。

## 静态依据与迁移差异

依据原部署包反编译的 `outputs/analysis/decompiled/com/headfree/wuzi/service/rpa/impl/CalPointServiceImpl.java` 124–300行；名称/参数来自 `wuzi-mszb/deps/mysql/init_data.sql` 26989–26994、27102–27107行。没有运行原网站，静态分析不代表与原网站运行结果逐项对照。

原版按分标编号/分包编号分组，本版采用明示名称键；原版14列固定位置、只读首sheet，本版表头识别、支持多个sheet；原版重复轮次时丢弃“第2轮”（BusBidListServiceImpl:276），本版要求选择轮次；原版最低价并列的可疑求和分支被拒绝；原版折扣率基准价也除10000，本版按报价类型展示；原版double均值改用十进制，极端舍入临界点可能不同。原版未进入详评表自动排除未迁移，使用者提供有效报价集合。

验证以合成工作簿覆盖六公式、百分比、轮次、重复报价、混合单位及空区间边界；现场数据尚待验证。

## 界面公式说明

工具5提供公式说明、本批配置、使用说明/运行结果三个页签。输入区“模板使用公式”和公式说明下拉框同步：选择六种公式之一，导出填写模板时自动填入公式名称，仅保留该公式所需参数列。分标名称和参数数值留空，新增分标行时可复制已填公式单元格。选择不会覆盖已导入参数表，实际计算仍以表中配置为准；六种方法分别展示步骤、基准价与评分表达式、参数范围和评分示例。qz=30代表30%。本批配置点击读取当前参数表后显示校验通过的分标、方法、权重快照，文件修改后须重新读取。配置预览和执行共用同一参数解析与校验入口。开始处理自动切换运行结果页。
