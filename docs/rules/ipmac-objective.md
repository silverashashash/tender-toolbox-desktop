# IP/MAC 与专家客观分迁移

本批为Mac开发验证版。原版依据为此前反编译得到的 IpAndMacApi / ObjectiveScoringApi，本次复用静态证据，没有运行原网站。新处理器仅读输入并输出本机Excel，不要求数据库或登录。

## 工具3：硬件联合核验（2026-10-23修订）

以用户提供的采购文件条款为业务依据，替换原版单字段重复规则。原23列文件读取兼容性保留：B分标名称、D分包名称、E轮次、F投标人，H—K四类IP、L—O四类MAC、P—S四类CPU、T—W四类硬盘。保留原列顺序。填写模板及上传统计表仍能解析，只有IP的记录会明确列为资料不足，不输出假无问题结论。

按同一分标名称＋分包名称核验不同投标人，跨轮次、跨文件类别比较。CPU与硬盘必须来自同一条文件类别记录且同时相同；双方MAC均存在时还要求MAC相同。不得拼接不同文件类别的CPU与硬盘构造命中。多选输入合并处理，不同采购批次须分开运行。

本次对条款未明确的细节采用以下显式执行口径：任一类别包括跨技术/商务/价格/资格业绩比较；MAC双方无值时以CPU＋硬盘一致列为“硬件组合一致（双方无MAC）”，仅一方无MAC列为“待人工核实（单方缺MAC）”，不直接列为三项一致。CPU或硬盘缺失但存在其他设备/IP值时列为资料不足。全空类别不参与；所有记录均无完整CPU＋硬盘时额外提示未完成核验。

IP（含下载IP）不参与联合判定。空白、/、／、-、—不作为有效硬件值；完整字符串相等才算相同，不拆分多设备值，不改变大小写或分隔符。同一供应商自身重复不触发；相同供应商及硬件组合归并各文件类别和来源。输出双供应商、核验状态、CPU、硬盘、双方MAC及来源行/轮次。程序输出为证据核验结果，供结合原投标文件复核。

模板导出文件名为IP_MAC对比工作簿-填写模板.xlsx；界面空输入框显示投标文件IP地址一览表.xlsx。

实测两份真实23列文件（104行CY1224SCZ024、350行12F701）按联合逻辑均无命中及资料不足记录，独立openpyxl核对一致。历史53/144条为旧单字段预警，不是新规则命中。输出保存在outputs/analysis/ipmac-joint-verification，原文件未修改。

## 工具9：专家客观分校验

原版由ZIP目录确定分标，从评分表文件名确定专家，通过用户选择的细则检查各专家分数一致及是否为指定整数的倍数。原版按字符串比较分数、按包含匹配细则，并会覆盖重复专家/细则记录。

新版直接多选解压后的.xlsx/.xls，不直接上传ZIP。文件名为“评分表_专家编号_专家姓名.xlsx”；保留专家编号和姓名以免同名专家混淆。分标名称从第二行设备/材料名称提取，遇分包编号、项目单位、工程名称或日期字段结束，也可在界面指定同一分标名称。工作表名是包名。

格式沿用原版：第3行B列为商务评分细则或技术评分细则，第4行D列起是供应商，第5行起是评分项，A/B列出现合计为结束。自动识别项目数，原格式每页项目数+8行；实际按组导出表含“第n页/共m页”页码行时每页项目数+9行。分页缺损、重复专家、同专家同供应商同细则重复、缺失/非法分数明确报错，不覆盖或跳过。

点击导出填写模板获得“客观项规则表”：每行填写一个选中的完整细则名称，步长可留空。细则按完整名称匹配，不自动将所有项目视为客观项。步长支持正小数，例如0.5；0或负数拒绝。2与2.00视为同分，使用底层数值，避免显示格式四舍五入。仅比较同分标、包、供应商、细则的分数。

输出专家客观分核验.xlsx：分数不一致、步长不符、专家记录缺失、专家数量不足、细则未找到等，带具体专家分数和来源位置。只有一位专家的评分明确提示无法核验一致性；规则未命中不会输出假“无问题”结论。评分细则在不同文件中须保持一致，主观项由用户排除。

## 验证范围

合成工作簿测试覆盖原版23列解析、同包不同供应商/跨轮次范围、不同标包隔离、占位符、错表头、数字格式等价、负分扣分、带页码分页、小数倍数、分页供应商、缺少专家和细则精确匹配。界面演示通过统一表单→处理器→实际Excel输出。工具3已用用户提供的两份上传统计表验证：396行应答数据输出0条预警，7883行投标数据输出70条预警；使用独立openpyxl读取（普通模式）按相同分组规则比对结果一致。工具9真实业务样例及两工具的原网站输出对照仍待验证。其余1预警事项确认单、5价格分、10授标、14智能分包尚未开放。

2026-10-23 实际工具9输入验证：7位专家、13个包、14项细则，共7546个分数单元格。临时以全部细则检查读取，1078组比较结果由独立openpyxl复算一致；这不是客观项正式核验。用户选择自行提供客观项名单，正式规则表及正式核验待名单，未自动判定任何细则属于客观项。输入文件无需改名改表。

2026-10-23 工具9支持界面勾选：选择评分文件后点击“读取评分项并勾选”，从所选工作簿所有工作表提取完整细则名、去重显示；默认不选。支持全选/全不选及可选正数步长。确认后自动生成会话规则文件，不改变结果保存目录，可再次调整；重新选择评分文件会清除旧规则与勾选。仍可手工选择已有规则表。实际7文件成功提取14项，Mac演示完成勾选到运行保存全流程。无需用户另行提交名单。

2026-10-23 多评分办法：读取每页完整、有序的“项目名称＋细则（含原分值文字）”定义，将一致定义归为一个评分办法。每种办法单独标签页，显示适用分标/包，各页选择与步长独立；空页不参与。自动生成规则增加评分办法标识，只应用于匹配办法的工作表；旧两列规则表继续按全局规则解释。不同专家同一标包办法冲突、同工作表分页办法变化或已选办法未匹配输入均报错，避免静默混用。规则标识由完整定义稳定计算，非界面页号。

真实技术评分样例：7份文件各33个sheet，缺包31，包号至34。7项办法适用32包，8项办法适用包34。分别用全部细则做格式/范围诊断（不代表认定客观项），结果509/12组评分差异，与独立openpyxl比较一致，无跨办法细则未找到误报。真实表头重复设备/材料名称标签的分标提取同时修正。
