# 工具10：离线授标模拟

输入技术经济指标综合评分及排序表（多选），或填写候选模板。原表每个 sheet 为一个包，第4行提供分标编号及设备/材料名称，第6行表头；支持14列评分排序格式与11列简化格式。候选模板：分标编号、分标名称、包名称、投标人、排序、投标总价。无候选包可仅填前三列。

算法信任输入“排序”，不重新计算分数，不使用“推荐排序”。同包重复投标人或并列排序拒绝处理，必须先确定唯一排名。

## 模式

- 无限授：各包选排名第一者。
- 一轮一包：每组各包选出未达到限授数的最高排名候选；按该候选投标总价从高到低、授标顺序从小到大、输入文件及工作表顺序选择一个包，计数后重新取候选。
- 一轮多包：每轮各包选出可授候选，按候选投标人分组，每人按上述优先顺序授其剩余名额数量，再进入下一轮。

限授配置每行一个包：限授组、分标编号、包名称、最大中包数、授标顺序。分标编号+包名称精确匹配，组可以跨分标，组内最大中包数必须一致；同一包不能重复配置。未配置的包按无限授处理，各限授组独立计数。只处理一次采购批次，请勿混入不同批次同名包。一个限授组中的报价必须为可直接比较的相同口径和单位（不要把金额与折扣率混合比较）。

输出所有包及拟授标人、轮次、来源。无候选、限授后无可授候选均保留明确状态。价格及授标顺序相同按输入文件/工作表顺序处理，并在说明列提示人工复核。结果是辅助模拟，使用前应核对采购文件授标规则。

## 界面与模板（2026-10-27）

授标方式使用下拉菜单，切换时日志展示对应原则；执行和导出后仍附带规则说明。无限授只导出技术经济排序表模板，不导出或使用限授配置。两种有限授导出相同的限授配置表，最大中包数均为组内每家供应商累计上限，授标顺序均为报价相同时的包优先级；不会因方式选择自动改写业务参数。
