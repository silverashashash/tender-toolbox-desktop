# 工具14 智能分包

输入为本地物料工作簿与分包规则工作簿，读取全部工作表。表头可定位，无需固定列顺序。输出为 `分包结果数据.xlsx`，包含“汇总”和“分包结果数据”。不依赖数据库或原网站。

## 填写与参数

物料表：序号、物料编码、物料描述、物料长描述、计量单位名称、技术规范书ID、扩展描述、数量、单价限价，以及可选的“分配粒度（可空）”。物料编码＋扩展描述必须唯一，重复请先合并数量；数量、单价、填写的粒度均必须为正数。编码、扩展描述分别保存，不以连字符拆解身份。

分包规则：包号、分配值。一行一个包，包号不可重复。“比例”模式将分配值作为正权重（如 1、1、2）；“金额”模式将分配值作为该包目标金额。金额合计不能超过物料总金额，且必须与物料单价使用相同货币单位。包数由规则行数确定。

重量粒度默认 1 千克，长度粒度默认 1 米；其他单位默认粒度 1。吨、千米内部转换为千克、米。物料表自定义粒度按该行原单位填写，并优先于默认粒度。例如单位吨、粒度 0.1 表示100千克。粒度不是硬性整除约束：最后不足一个粒度的余量仍保留并分配，不丢弃。

## 分配逻辑

1. 按目标金额从高到低，依次给每包每种物料分配一个粒度；库存不足时分配剩余量。首次分配也可能超出目标金额。
2. 冻结第一轮后的剩余数量，按各包剩余目标金额比例、以粒度取整分配，最多分配实际剩余量。
3. 尾料按单价从高到低，以粒度为块轮流分到各包，最后不足一块的余量也分配。完整轮次按乘法汇总，不创建海量尾料块。

汇总提供实际金额、目标金额和“实际减目标”。这是数量分配建议，并非金额硬限额或最优解；不同计量单位的总数量只是机械汇总，不能作为同一单位的业务总量。每种物料数量和按原始单价计算的总金额必须严格守恒，程序在输出前校验。
